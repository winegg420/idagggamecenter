# Bildim! — İçerik derecelendirme anketi cevapları

Play Console → App content → Content rating. IARC anketi.

| Soru | Cevap |
|---|---|
| Uygulama kategorisi | Oyun — Bilgi Yarışması / Eğitim |
| Şiddet içeriyor mu? | Hayır |
| Cinsellik içeriyor mu? | Hayır |
| Küfür / kaba dil? | Hayır |
| Uyuşturucu, alkol, tütün? | Hayır |
| Kumar veya kumar simülasyonu? | **Hayır** — jokerler oyun içi para değil, şans oyunu yok |
| Korku öğeleri? | Hayır |
| Kullanıcılar birbiriyle etkileşebiliyor mu? | **Evet** — hazır emoji ve kalıp mesajlar |
| Serbest metin sohbeti var mı? | **Hayır** — yalnız önceden tanımlı 6 emoji ve 8 kalıp cümle |
| Kullanıcı konumu paylaşılıyor mu? | **Evet, sınırlı** — yalnız kullanıcının seçtiği şehir/ülke, ligde görünür |
| Kişisel bilgi paylaşımı? | Takma ad ve avatar (kullanıcı seçer) |
| Uygulama içi satın alma? | **Evet** — joker paketleri |
| Reklam gösteriliyor mu? | **Evet** — ödüllü video ve maç arası geçiş reklamı |
| Dijital satın alma yapılabiliyor mu? | Evet |

**Beklenen derecelendirme:** PEGI 3 / ESRB Everyone / USK 0
(kullanıcı etkileşimi nedeniyle "Kullanıcılar etkileşebilir" uyarısı eklenir).

## Veri güvenliği formu (ayrı bölüm)

| Veri türü | Toplanıyor | Paylaşılıyor | Neden |
|---|---|---|---|
| E-posta adresi | Evet | Hayır | Hesap oluşturma ve giriş |
| Ad (takma ad) | Evet | Hayır | Sıralamada görünür |
| Yaklaşık konum (şehir) | Evet | Hayır | Şehir/ülke ligi — kullanıcı elle seçer, GPS kullanılmaz |
| Oyun içi eylemler | Evet | Hayır | Puan, sıralama, istatistik |
| Reklam kimliği | Evet | **Evet** | AdSense / H5 Games Ads |
| Satın alma geçmişi | Evet | Hayır | Joker paketleri |

- Veriler **aktarımda şifrelenir** (HTTPS).
- Kullanıcı hesabını uygulama içinden silebilir (Profil → Hesabımı sil),
  silme tüm oyun verisini kaldırır.
